# Güvenlik Politikası

## Desteklenen sürümler

Yalnızca en güncel beta sürümü güvenlik düzeltmeleri alır.

## Güvenlik açığı bildirimi

- Açığı herkese açık bir issue olarak açmayın.
- GitHub üzerinden özel güvenlik bildirimi (Security > Report a vulnerability) kullanın.
- Bildirimde: etkilenen sürüm, yeniden üretme adımları, etki ve varsa önerilen düzeltme bulunmalıdır.
- 72 saat içinde ilk yanıt hedeflenir.

## Kapsam

- WinNexus yönetici izniyle çalıştığı için komut enjeksiyonu, yol aşımı, yetki yükseltme ve registry mutasyonları önceliklidir.
- Üçüncü taraf bağımlılık açıkları Dependabot ve GitHub güvenlik uyarılarıyla izlenir.
